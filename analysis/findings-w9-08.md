## Cross-Session Patterns

### Pattern: BMAD skill sessions are REVIEW/PLANNING, not BUILD

Sessions 9b34fa2f and dca77664 both use BMAD skills (`/bmad-check-implementation-readiness`, `/bmad-sm`). Both are planning/review work — zero product code created. BMAD skill invocation in SupportSignal should bias toward PLANNING/REVIEW, not BUILD.

### Pattern: v-appydave sessions are OPERATIONS, not BUILD

Both v-appydave sessions (88e68402, dc3ef96a) are dominated by git operations, cleanup, and repo housekeeping. 88e68402 has genuine Edits but they're YAML text changes via delegation — more OPERATIONS than new feature construction. v-appydave CWD should bias toward OPERATIONS.

### Pattern: prompt.supportsignal CWD is always incidental

3/3 prompt.supportsignal sessions in this batch confirm it: one iTerm shortcut question, one session-context query, one prior-session paste. CWD is a home terminal. Previous wave 5 finding confirmed at N=8+.

### BUILD accuracy in this batch: 1/9 (11%)

Only 88e68402 has genuine code edits, and even that is arguably OPERATIONS (delegation-driven YAML field renames). Registry would have classified most of these as BUILD. Actual BUILD rate in this batch is 0-11%.
